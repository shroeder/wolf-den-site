⚠️ First, a correction to my own Cogfall doc

It says No town is in code yet and gives Cogfall five invented buildings. Both wrong. I took that from docs/grove-towns-design.md, which opens Nothing is in code yet and was written two days ago.

The truth: TOWNS holds seven live towns, acts.js holds Acts I–VII with quests and tool-slot perks, TownClient.js renders a parallax street, and 57 town sprites are on disk.
